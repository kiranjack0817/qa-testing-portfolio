
# Manual QA Portfolio — Web Application Testing

**Project type:** Independent QA portfolio project  
**Status:** In progress  
**Focus:** Functional, exploratory, negative, boundary, and regression testing

## Overview

This repository demonstrates a structured approach to testing a web-based e-commerce application. It showcases test planning, test design, execution, defect reporting, and risk-based quality assessment.

The objective is to produce clear, reproducible QA evidence that a development team can use to understand product risks and make informed release decisions.

## Application Under Test

- **Application:** [SauceDemo](https://www.saucedemo.com/)
- **Application type:** Sample e-commerce web application
- **Testing approach:** Manual functional and exploratory testing
- **Scope:** Authentication, product inventory, sorting, shopping cart, checkout, and validation.

## Testing Deliverables

The repository will contain:

1. Test plan and scope
2. Detailed test cases with expected results
3. Exploratory testing checklist
4. Reusable bug report template
5. Test execution report
6. Supporting evidence for verified findings, where appropriate

## Testing Approach

- Validate critical user journeys and business rules.
- Cover positive, negative, and boundary scenarios.
- Check required fields, invalid inputs, and error handling.
- Prioritise defects based on severity, impact, and reproducibility.
- Record actual outcomes and distinguish verified defects from expected behaviour.

## Execution Results

Test execution and results will be documented after the scenarios have been run against the demo application.

No defect counts, pass rates, or coverage metrics will be claimed before they are measured.
